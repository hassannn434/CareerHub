# CareerHub AI

This repository contains the Phase 1 scaffold for CareerHub AI — Smart Campus Career & Placement Platform.

Phase 1 includes:

- Project folder structure
- PostgreSQL schema (database/init.sql)
- Backend scaffold (FastAPI) with a /api/v1/health endpoint
- Minimal ML module (ml/job_matcher.py) implementing TF-IDF + cosine similarity matching
- Docker Compose for local Postgres

Next steps: implement Authentication, Pydantic schemas, Alembic migrations, and frontend pages.
